# Enemy Crawler C v01

C案「多関節の這い寄り型」の外見・動作確認用初版です。完成品質の写実的キャラクターとしての最終承認前のデータです。

## 内容

- `Enemy_Crawler_C.fbx`: メッシュ、UV、マテリアル、スキニング、11クリップ。
- `CrawlerC_Review.blend`: 編集用データと撮影シーン。
- `textures/`: 5マテリアル分の2048 x 2048 BaseColor、Normal、Normal_DX。粗さ・金属度はマテリアル定数。
- `previews/`: 全身・正面・側面・頭部と、攻撃・光ひるみ・死亡・壁這いの確認画像。
- `validation_ufbx.txt` / `validation_blender.json`: 書き出したFBXの検査結果。

全体131,648三角形、5メッシュ、64変形ボーン（FBXのスキンクラスターはルート込み最大65）、頂点当たり最大4ウェイト。約2mの体格、這う高さ約60cmを基準に作成しています。灰白色の皮膚、小さな白濁した目、指先と顎の感覚器官を備え、流血・内臓露出はありません。

## アニメーション

60fpsでベイク済み。FBXのクリップ名には `CrawlerC_Rig|` が付きます。

| 名前 | 秒 | ループ |
| --- | ---: | --- |
| 00_Idle | 3.0 | Yes |
| 01_Patrol_Crawl | 2.4 | Yes |
| 02_Alert | 1.0 | No |
| 03_Search | 3.0 | Yes |
| 04_Chase | 0.9 | Yes |
| 05_Attack | 1.2 | No |
| 06_Hit | 1.0 | No |
| 07_LightFlinch | 1.5 | No |
| 08_Death | 2.0 | No |
| 09_LightBoundary | 2.4 | Yes |
| 10_WallCrawl | 2.0 | Yes |

`07_LightFlinch` は中程度の反応で、前肢を頭側へ引き上げて身を引き、元の姿勢へ戻ります。死亡は最終フレームを保持してください。指はリグで編集できますが、現在の動作は主に手全体の接地・探索で、指ごとの独立した探索動作は未調整です。

## エンジンへの導入

FBXとtexturesフォルダーの相対配置を維持してください。既存エンジンのufbx設定に合わせ、メートル単位・Y-upへ変換した読み込みを検証しています。Blender原本はZ-up・前方-Y、エンジン上の前方は-Zです。

移動クリップはその場再生です。速度・位置・旋回・壁への姿勢合わせ・衝突・聴覚AI・光判定・ダメージ判定・アニメーション遷移はゲーム側で処理してください。WallCrawlもローカル接地面を使い、ゲーム側で壁の法線に合わせます。床から壁へ乗り移る専用遷移は含みません。壁の画像は姿勢合わせの例で、壁メッシュはFBXに含まれません。

DX向けノーマルは `*_Normal_DX.png`、Blender原本向けは `*_Normal.png` です。既存ローダーに合わせて粗さ・金属度をFBXに記録しています。エンジンコードと既存アセットは変更していません。

## 検証と残作業

ufbxで全11クリップを60Hzベイクし、各クリップ9姿勢の変形、有限座標、ウェイト、骨数、ループ端点、床への大きなめり込みを検査しました。BlenderでFBXを再読み込みし、三角形・UV・ウェイト・全クリップ・2K画像・8枚の非空プレビューを検証しています。これらは全フレームの自己交差や足滑りを保証する検査ではありません。

ゲームへの組み込みと実機60fps測定は未実施です。60fpsはアニメーションのサンプリング設定であり、描画性能の保証ではありません。外見には単純な丸みが残り、写実的な皮膚・解剖学的な造形の仕上げ、LOD、指の細かな演技は今後の調整項目です。

生成・検査用スクリプトは `tools/crawler_c_v01/` にあります。生成処理は既存の `tools/lab_assets_v01/build_lab.py` のFBXマテリアル出力補助を読み込みます。
